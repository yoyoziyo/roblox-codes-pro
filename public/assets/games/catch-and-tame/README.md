# Catch and Tame

Substitua este arquivo pelos assets locais quando estiverem disponíveis:

- `icon.webp` — imagem quadrada;
- `banner.webp` — imagem horizontal principal;
- `thumbnail.webp` — imagem otimizada para cards.
- `redeem-tutorial.webp` — captura que mostra onde e como resgatar os códigos.

Depois atualize `data/games/catch-and-tame.json` e `data/index.json` para apontar para os arquivos locais.

Enquanto `redeem-tutorial.webp` não existir, a página exibirá um placeholder e manterá o restante do tutorial disponível.
