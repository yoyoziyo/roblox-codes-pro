# Assets compartilhados

Coloque aqui os elementos reutilizados em todas as páginas:

- `logo.webp`: mascote do site, até 256 × 256 px;
- `language.webp`: seletor de idioma, até 64 × 64 px;
- `verified.webp`: selo de verificação, até 96 × 96 px;
- `roblox.webp`: símbolo do botão “Abrir no Roblox”, até 64 × 64 px;
- `codes.webp`: ícone de códigos ativos, até 96 × 96 px;
- `tips-icon.webp`: ícone pequeno de dicas, até 96 × 96 px;
- `tips.webp`: ilustração grande do card de dicas, até 512 px no maior lado;
- `discord.webp`: símbolo ou ilustração da comunidade, até 192 px no maior lado;
- `favicon.png`: ícone da aba e fallback final, 192 × 192 px.

Use WebP com transparência para todos os elementos visuais, exceto o favicon, que permanece PNG. Todos possuem fallback: se o arquivo ainda não existir, o símbolo atual continua visível e a página não quebra.
